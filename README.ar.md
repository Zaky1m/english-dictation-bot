# eng

[English](README.md)

ميني آب تيليجرام لتعلّم الإنجليزي بالإملاء. المتعلّم يسمع الجملة ويشوف ترجمتها بالعربي ويكتبها بالإنجليزي.
الباك إند مكتوب بـRust (axum وPostgreSQL) وبيخدم ويبهوك البوت وواجهة JSON والميني آب نفسه.
الإجابة بتتفحص على السيرفر، فالعميل عمره ما بيمسك الحل قبل ما الجملة تتحل أو تتكشف كلمة.

![خريطة الدروس على نافذة كمبيوتر](docs/screenshots/map-desktop.png)

## المميزات

- 20 موقفًا، في كل موقف 6 دروس، وفي كل درس 10 جمل (1200 جملة)، مكتوبة مرة واحدة بـGemini ومفحوصة بفحوصات آلية.
- صوت لكل جملة ولكل كلمة، بيتولّد مرة واحدة ويتخزّن MP3 ويتقدّم كملفات ثابتة.
- خانة إدخال لكل كلمة. السيرفر بيرجّع أماكن الحروف الغلط، والإجابة الصحيحة بتتبعت بس بعد الحل أو كشف كلمة.
- حساب النقاط على السيرفر: دقة ومكافأة سرعة وكومبو وحماية بسيطة من الغش.
- هدف يومي وسلسلة أيام (ستريك)، مع تجميد شهري للسلسلة لمشتركي Pro.
- مراجعة متباعدة للجمل اللي فيها أخطاء (بعد 1 ثم 3 ثم 7 أيام).
- دوري أسبوعي بسبع درجات مع ترقية ونزول.
- تحدي يومي بلوحة ترتيب خاصة.
- شارات وكلمات محفوظة وإحصائيات (رسوم وأكتر الحروف غلطًا لمشتركي Pro).
- اشتراك Pro بنجوم تيليجرام، أو بمنح يدوي من الأدمن.
- إعلانات مكافأة اختيارية عن طريق Adsgram.
- لوحة أدمن للمستخدمين ومنح Pro والمدفوعات والإعدادات والمحتوى.
- واجهة عربي وإنجليزي (RTL وLTR). على الكمبيوتر بيفتح بملء النافذة وفيه اختصارات كيبورد.

## المتطلبات

- Rust (نسخة stable، إصدار 2024) وقاعدة PostgreSQL 16.
- `ffmpeg`، لتوليد الصوت بس.
- توكن بوت تيليجرام من BotFather.
- مفاتيح Gemini، لتوليد المحتوى والصوت بس.
- رابط HTTPS عام للويبهوك والميني آب.

## التشغيل محليًا

```bash
cp .env.example .env          # املا القيم
cargo run --release -- serve
```

أمر `serve` بيطبّق الـmigrations ويسجّل الويبهوك ويشغّل السيرفر. ابني دايمًا بـ`--release`.

المحتوى بيتولّد بنفس البرنامج:

```bash
cargo run --release -- content generate --all   # جمل كل المواقف
cargo run --release -- content audio            # الصوت الناقص للجمل والكلمات
```

بـDocker، ملف `compose.yml` بيشغّل التطبيق وPostgreSQL مع بعض:

```bash
cp .env.example .env
docker compose up --build
```

## الإعدادات

كل حاجة من متغيرات البيئة (شوف `.env.example`):

| المتغير | الغرض |
|---|---|
| `BOT_TOKEN` | توكن بوت تيليجرام |
| `PUBLIC_URL` | عنوان HTTPS العام للميني آب |
| `BIND_ADDR` | العنوان اللي السيرفر بيسمع عليه |
| `DATABASE_URL` | رابط الاتصال بـPostgreSQL |
| `WEBHOOK_PATH` و`WEBHOOK_SECRET` | جزء مسار الويبهوك والهيدر السري |
| `ADSGRAM_REWARD_SECRET` و`ADSGRAM_BLOCK_ID` | إعلانات المكافأة، مقفولة لو الـblock id فاضي |
| `ADMIN_IDS` و`ADMIN_USERNAME` | أرقام الأدمنز، وحساب التواصل للدفع اليدوي |
| `CHALLENGE_CHANNEL_ID` | القناة اللي بيتنشر فيها ملخص التحدي اليومي |
| `DATA_DIR` و`WEB_DIR` | فولدر ملفات الصوت وفولدر الميني آب |
| `GEMINI_API_KEY_<n>` | مفاتيح Gemini بتتستخدم بالتناوب |

الأرقام زي الحدود اليومية والأسعار ومعاملات النقاط موجودة في جدول `settings` وبتتعدّل من لوحة الأدمن وتتطبق فورًا من غير ريستارت.

## البنية

برنامج واحد اسمه `eng` وأوامره: `serve` و`content generate` و`content audio` و`content voices` و`webhook set`.

```
src/
  http/        الراوتر والمصادقة وملف لكل جزء من الـAPI
  telegram/    معالجات الويبهوك ونصوص البوت وsmall caps والدفع
  exercise/    التقسيم والفاحص وحساب النقاط (دوال نقية)
  content/     توليد الجمل والفحص والصوت ومهام الأدمن
  gemini/      مجمع المفاتيح وعملاء النص والصوت وتنضيف الصوت
  jobs.rs      الشغل المجدول: الدوري والتحدي اليومي والمسح والتذكير
migrations/    migrations بتاعة sqlx
web/           الميني آب (HTML وCSS وJS عادي بدون build)
texts/         رسايل البوت بالعربي والإنجليزي
```

كل الحالة الدائمة في PostgreSQL. الحالات المؤقتة (المحاولات المفتوحة ومعرّفات التحديثات وكريديت الإعلانات غير المستخدم) بتتمسح بعد يوم على الأكتر.
أسباب القرارات الأساسية في [docs/DECISIONS.md](docs/DECISIONS.md) وسلوك المنتج في [docs/SPEC.md](docs/SPEC.md).
