# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: open the **Security**
tab of this repository and choose **Report a vulnerability** (GitHub private
security advisories). Do not open a public issue for a security problem.

Include what you found, how to reproduce it, and the impact you expect. You
should get a first answer within a few days.

## Scope

The bot webhook, the JSON API, the admin panel, payment handling (Telegram Stars
and the ad reward callback) and the authentication of Mini App requests are in
scope. Reports about third-party services (Telegram, Gemini, Adsgram) belong to
those vendors.

## Supported versions

Only the latest release receives security fixes.
